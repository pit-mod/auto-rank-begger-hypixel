# Auto Rank Begger Hypixel

Forge 1.8.9 mod that auto-sends rank gift beg messages in Hypixel chat, with optional Discord webhook alerts when someone gifts you.

## Build

```bat
gradlew.bat build
```

Output: `build/libs/RankBegger-1.0.jar`

## Usage

- Open ClickGUI (module included)
- Configure messages, delay, smart mode, typing simulation
- Set your own Discord webhook URL in settings (optional)

## Requirements

- Minecraft 1.8.9 + Forge `11.15.1.2318-1.8.9`
- Java 8

## Disclaimer

Automated chat can violate Hypixel rules. Use at your own risk.
